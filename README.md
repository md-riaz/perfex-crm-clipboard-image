# Perfex CRM Clipboard Image Module

A small Perfex CRM module that uploads clipboard-pasted images and keeps them inline in task descriptions and comments instead of creating ordinary task attachments.

## Install

Copy `modules/clipboard_image` into the `modules` directory of a Perfex CRM installation, activate it from **Setup → Modules**, then hard-refresh the admin page.

The module expects the standard Perfex task editor, authenticated staff access, and the existing task upload storage.
